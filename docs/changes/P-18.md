title: The formal solution reads the background opacities from a read-only mapping of `background.dat` instead of with `pread`

`readBackground` read each block of background opacity, emissivity and scattering with `pread` into a conversion buffer (float on disk since M-1) that it allocated and freed on every call, and the formal solution calls it for every wavelength, and in a moving or polarized atmosphere for every ray and direction, in every sweep. The file is in the page cache, or in /dev/shm, so this was system calls and copies, not disk I/O: 6 % of the worker samples on a 1-D Bifrost column with 118 501 wavelengths, and most of the system time left after P-16, growing with the number of threads.

`Background()` now maps the file read-only (`mapBackground`) once it has written it, or opened it with `OLD_BACKGROUND`, and `backgroundIO` converts the values straight from the mapping, with the same expressions as before; `readBackground` allocates no buffer when the file is mapped. The mapping is removed before the file is written again or closed (`closeBackgroundFile`, B-39), and needs no memory of its own: it shares the pages of the page cache. If the file cannot be mapped, `pread` is used as before, and so do the programs that open the file themselves (`solveray`, `chartflow`).

1-D Bifrost lane column (77 points, Fe I+II and Mg active, 118 501 wavelengths, moving, hybrid PRD, `OLD_BACKGROUND`), three iterations, Apple M2 Pro, before → after: 1 thread 130.0 → 122.5 s in the iterations, system time 15.5 → 5.0 s; 4 threads 43.7 → 40.1 s, 30.8 → 7.1 s; 8 threads 26.9 → 24.2 s, 54.3 → 6.8 s. Populations, J, Jgas, flux and spectrum are identical to the bit on one thread. With the file written afresh and rewritten: FAL-C, Ca II active, `SOLVE_NE = ITERATION` (`Background()` called 8 times, the mapping removed and made again each time), 4 threads, populations, J, flux and spectrum identical to the bit. ctest 33/33.

The memory case of `tests/run_tests.sh` (`2d/mem`) compares peak RSS, which now includes the pages of the mapped file that the run reads (26 MB there): clean page cache, not memory the program allocates; its peak memory footprint (macOS) went from 115.7 to 113.9 MB, since the per-read buffer is gone. The case no longer counts the size of `background.dat` for a program that maps it (`mapped_mb`, recognised by the text of its warning), for the baseline as for the candidate. Checked: P-17 against P-18, P-18 against itself and P-16 against P-17 all pass; the growth the case guards against (about 85 % from per-wavelength caching) is much larger than the file.
