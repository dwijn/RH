title: The three later e2e scripts (hydrostatic_final, solver_ng_restart, eddington_2d) use tests/rhtest

N-16, N-36 and B-57 added three end-to-end scripts in the old self-contained style, after Q-31 (#407) had moved the first eight onto `tests/rhtest/`. They are ported the same way: the argument parsing, work directory, `setkw`, run-directory preparation, execution, binary readers and bookkeeping come from the package. Results are unchanged and so is what the tests check: same cases, keyword values, tolerances (the exact equalities of `eddington_2d` stay exact), and exit statuses. Line counts: `hydrostatic_final` 234 to 121, `solver_ng_restart` 158 to 96, `eddington_2d` 408 to 318 (800 to 535); `rhtest` grows from 419 to 529 lines with the additions below (output readers 133, run 148), and `solveray_cosines` shrinks from 103 to 100.

Additions to `rhtest`, each used by one of the three and generic: `output.read_pops_array` (Nlevel, Nspace and the populations; `read_pops` is its third item), `xdr_counted_string`, `read_atmos_out` (T, nHtot, abundances of `atmos.out`), `read_first_molecule` (ID and temperature range of `molecules.out`), `read_spectrum` (unpolarized `spectrum.out`), `read_solveray_intensity`; `run.execute_streaming` (the run read line by line with a callback, a timer that kills it; `hydrostatic_final` creates `STOP_RH` from it), `run.make_field` (the `tests/make_field.py` call, now also used by `solveray_cosines`), `execute(..., log=)` and `Result.require(ok=None)` (any status). The 2-D atmosphere file layout of `eddington_2d` and the `inconsistency` measure of `hydrostatic_final` stay in their scripts, with one user each.

Measured: each script run on the same build with the old and the ported version (`--work`), the work trees compared. All 113 input files (`keyword.input`, `atoms.input`, the copied `molecules.input` and `ray.input`, the 2-D atmosphere files, the field file, `kurucz.input`) are byte-identical, and the 501 compared files include the outputs, equal apart from `time.out`, modification times of the atmosphere file embedded in some outputs, and absolute paths in `keyword.input`. The only extra file is `ray_B_main/solveray.log` (the solveray log of `eddington_2d`'s field case, kept apart so that the main run's `out.log` stays). The `STOP_RH` case of `hydrostatic_final` was repeated five times: every run stopped after three iterations with a Ca II inconsistency of 1.10E-06 and byte-identical `pops.CA.out`, `pops.H.out` and `atmos.out`. Failure path: a program exiting 2, and a tolerance of 1e-9 in `eddington_2d`, both give exit status 1 with the work directory kept and named; a passing run leaves `$TMPDIR` empty. Small differences: `hydrostatic_final` reports a first molecule that does not parse as `ValueError` where it printed a message and exited; summary lines are unified as before.
