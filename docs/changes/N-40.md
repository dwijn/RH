title: A negative total opacity that would overflow the formal solution stops the run with a message, or rejects the trial point

Where the total opacity is negative (a strong inverted line, SOLVER.md trap 5), the intensity grows as exp(−τ) across the run of negative optical depth, and the formal solvers overflow once that run is deeper than about −709: the run died with SIGFPE, or without floating-point traps carried inf and NaN into J and the populations, with nothing saying where. Nothing caught it before: the line test of Anderson's guard did not keep the total opacity positive (S-13, S-14).

Each `Formal()` (1-D, 2-D, 3-D, spherical) now checks the opacity of every wavelength and ray before solving (`negtau.c`). It takes the optical depth of each interval along the ray (2-D and 3-D: in the column where it is most negative, a bound for a ray that crosses columns; spherical: along the ray's own path) and sums it over runs of consecutive negative intervals. A run below −50 (`NEG_TAU_LIMIT`; overflow is at about −709, and the S-5 set never goes below −0.1) skips the rest of that wavelength, before anything can overflow. Then:

- Outside a trial point (the initial lambda iteration, plain and Ng steps, the final formal solution, every solver), `solveSpectrum` stops the run with a message naming the wavelength, the ray, the depth intervals, the column in 2-D and 3-D, and the optical depth, e.g. "negative total opacity at lambda = 393.449368 nm (wavelength 50), ray 0 downward: optical depth -120 over depth intervals 0-2 (limit -50)".
- At an extrapolated Anderson point, `G_eval` returns FALSE and the point is rejected like one that fails the safeguard: the history restarts and the next point is G at the last accepted point. The log says so for each one and counts them at the end. In Newton's line search the trial counts as a guard halving ("negative opacity").

Where no total opacity is negative the check is one pass over χ per ray; where it is negative but the runs are shallow (the S-5 set: −0.094 at most, on `falc_mgi66`), it changes nothing. `run_tests.sh --exact` against the S-14 build: 34 of 34 cases bit-identical. Unit test `test_negtau`: runs, threshold, the column bound, the message. The two paths and Newton's were checked with a scratch hook that fakes a detection at one wavelength (not committed): the stop in 1-D, 2-D and spherical geometry, and Anderson and Newton–Krylov rejecting every trial point and finishing normally.
