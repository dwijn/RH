title: The state is a parameter: RHState *rh comes first in the 451 functions that use it, and the global is gone (results and output unchanged)

The library and the geometry code reached the state of a run through a global pointer, `rh` (Q-45). Now every function that uses the state, or calls one that does, takes it as its first parameter, `RHState *rh`, and passes it on: 364 functions of the library and 87 of the geometry code. The global is gone, so the library cannot reach a state it was not given: a function that used `rh` without the parameter would not compile, and `librh.a` refers to no symbol `rh`. The function bodies did not change; they already said `rh->` (Q-45). The programs, the tools and the unit tests are clients: each keeps its own instance and a pointer to it (a static at file scope in the programs, the global of each tool and of the unit tests).

The messages changed names with it, since every call gained `rh` anyway. A call that reports no error is no longer named `Error`: `Message(rh, format, ...)` (109 calls), `Warning(rh, routine, format, ...)` (73) and, for fatal errors only, `Error(rh, level, routine, format, ...)` (487). Message and Warning are macros over one function, `Log(rh, level, routine, format, ...)`, which writes messages and warnings (and in phase 6 hands them to the caller's callback); macros, because C cannot pass `...` on and gcc and clang never inline a function with a variable argument list. Messages print no routine, so five helpers of the solvers lost the parameter that carried it.

Functions called through a pointer were converted by hand, with their types: the geometry operations, the work functions of `parallelFor`, the sweep of the background scattering iteration, the keyword and option setters, and the ray solvers that unit tests call through pointers. Thread start routines cannot take a parameter: the thread data carries `rh`, and so does the context of the Newton-Krylov products, which keeps `gmresSolve` free of RH's state. The opacity buffer pool was made by `pthread_once`, whose routine takes no argument; it is now made at first use under a lock.

Generated: the renaming of the 669 message calls (`q49_rename.py`) and the sweep that added the parameter to 719 declarations and definitions and the argument to 1940 calls in 182 files (`q49_sweep.py`, from the call graph of the commit it changes). Rerun, the scripts reproduce both commits, and two independent checks find nothing else in them. Results unchanged: `run_tests.py --exact`, and all files of the runs of the end-to-end tests compared with the base, byte for byte. Scripts and logs: `claude/RH/evidence/lib-q49-state-param`.

Fixes Q-4; part of Q-7; phase 3 of the library track (`docs/LIBRARY.md` §6.3).
