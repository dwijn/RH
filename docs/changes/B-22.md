title: w3js checks its arguments; 3j/6j overflow stops with an error

`w3js()` accepted arguments that violate the selection rules for j - m and j1 + j2 + j3 being whole (`w3js(0.5, 0.5, 0.5, 0.5, -0.5, 0)` returned 1); it now returns 0 for them. `fact()` returned 1 for a non-integer argument read past its table above 300, and every entry above 170! in it was infinite; it now holds 0! to 170! and stops with an error outside that range. The products of factorials in the Racah formulae overflow from j = 49, which gave +-inf (j = 50 to 56) or 0 (from j = 58); `w3js()` and `w6js()` now stop with an error instead. The only caller, `paschen.c`, uses small J, where nothing changes.
