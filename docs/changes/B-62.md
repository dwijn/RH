title: molecules.input must list H2 first, exactly; an empty list stops at input

RH uses `atmos.H2`, the molecule with ID `H2`, in the background opacities (H2- free-free, Rayleigh scattering by H2), in the collisions of an active CO or H2 and in hydrostatic equilibrium. It also takes `molecules[0]` for H2 in two places: `Background()` keeps `molecules[0]` when it frees the passive molecules, and `Hydrostatic()` decided on `molecules[0]`'s temperature range whether H2 is present at a depth point. `readMolecules` required the first molecule to be H2, but with a substring test (`strstr(ID, "H2")`), so H2+ or H2O first passed; an empty list was not checked. What that did (FAL-C, `rhf1d/run` inputs; evidence `/hao/solar1/dwijn/claude/RH/evidence/t13-b62/`):
- H2+ first and no H2, or no molecules: `atmos.H2` is NULL. Every run (not only `HYDROSTATIC = TRUE`) crashed with a segmentation fault in `H2minus_ff`, in the first Background().
- H2O first, H2 later: `Background()` freed the passive H2, so `atmos.H2` dangled (read afterwards by `COcollisions`/`H2collisions` of an active CO or H2). With `HYDROSTATIC = TRUE`, H2 was switched on and off by H2O's range (1000-6000 K instead of 1000-9000 K): converged nHtot (H_6 and Ca II active, `SOLVE_NE = ITERATION`, `ITER_LIMIT` 1e-3) off by 2.7e-4 at 6180 K on FAL-C, and by 4.5e-4 at 6200 K on FAL-C with T x 0.7.

`readMolecules` now stops with a message when the list is empty ("molecules.input lists 0 molecules: it must list at least H2, as the first molecule") and when the first molecule's ID is not exactly `H2` ("The first molecule in molecules.input must be H2, not H2O (...)"). The ID is compared after the molecule is read, as `atmos.H2` is set, so `atmos.H2 == &atmos.molecules[0]` from then on. `Hydrostatic()` takes the temperature range from `atmos.H2` (the same molecule now; the code says what it means). The log row proposed a check only for `HYDROSTATIC = TRUE`; since every run needs H2, the check is for all runs.

New e2e test `molecules_input` (ctest `e2e_molecules_input`): H2+ first without H2, H2O first, and an empty list each stop with status 70 and the message. On the old binary the first and the last end with a segmentation fault and the second runs.

Results unchanged: every shipped `molecules.input` lists H2 first; `run_tests.py --exact` is byte-identical. Same code upstream.
