title: The per-run statics of the library in RHState, one part per module (results unchanged)

37 static variables of the library held the state of one run, so a second solver in the process would have shared them. They are now fields of `RHState` (Q-45), one part per module, of a type declared in the module's header: `rh->solver` (`solver.c`, 18: the blocks of the state vector, the count of G evaluations, the residual history and the packing of the variables u), `rh->bgscatter` (the per-wavelength flags and the counters of the background scattering, with their mutex), `rh->negtau` (the detection record and the message of an invalid trial point, with their mutex), `rh->opacity` (the pool of opacity buffers per thread slot, with its once-control), `rh->background`, `rh->kurucz` and `rh->hydrogen` (whether the Kurucz lines have been read, the count of n_e solves, the per-point Kurucz tables and H₂ free-free indices), `rh->chemequil`, `rh->error` (the exit flags), `rh->getcpu` (the timer starts) and `rh->work` (the work counters). `solver.c`'s `Nstate` is now `rh->solver.Nstate`. The initial values that are not zero are in each module's `<MODULE>_STATE_INIT`, which `RH_STATE_INIT` collects; the tools use `RH_STATE_INIT` now too. The types the statics use moved with them (`StateBlock` to `solver.h`, `RLK_Tables` to `background.h`, `AsPool` to `spectrum.h`; the detection record of `negtau.c` is now `NegTauDetection`).

The survey counted 36 per-run statics and the opacity pool among the scratch buffers; the pool moves too, as the log row says, since the threads of one solve share it. Still static: the tables loaded once (phase 4), the scratch and return buffers and the three warn-once flags (phase 3), and the file handles (phase 5).

The rewrite was made by a script, `q46_rewrite.py`, followed by clang-format: the second commit is its output, and running both on the first commit reproduces it exactly. Machine code, built at -O0: the base, with each static turned into its field by the C preprocessor (`#define Nstate (rh->solver.Nstate)`), and this branch compile to the same instructions in all 360 object files, so the script rewrote exactly the uses the preprocessor does; a lock of the wrong module, put in on purpose, is found. The first commit, which moves only types, compiles to the same instructions as Q-45, and the initial values of the 40 moved statics (37 variables, 2 mutexes, a once-control) are the bytes of their fields in `RH_STATE_INIT`. Scripts and logs: `claude/RH/evidence/lib-q46-statics`.

Part of Q-4; phase 2 of the library track (`docs/LIBRARY.md` §6.3). Results unchanged: `run_tests.py --exact` against the base, all geometries.
