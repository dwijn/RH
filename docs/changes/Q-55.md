title: Errors that return, part 3: transfer, nlte and model return a status instead of ending the run (results unchanged)

The modules `src/transfer`, `src/nlte` and `src/model` had 28 places that end the process. 26 of them are gone; the two exits of the gcheck options (`gcheckParse`) belong to the programs and stay for that row. Each site was handled by its class in the Q-51 table and the rule of `docs/LIBRARY.md` §3.6:

- Dead code was deleted, with its 4 sites: `duplicateLevel` and `duplicateLine`, which nothing calls (upstream neither), and a test for NULL after `mallocOrAbort`, which never returns NULL. The comment in `metal.c` that said those functions keep an active atom's opacity from being counted twice now says what does: `metal.c` skips active atoms.
- An invariant that only a bug in RH can reach, with confidence high, became `RH_ASSERT` (7): the transition types in `Opacity`, `addtoGamma` and `addtoCoupling`, the topology in `initSolution`, and `negTauInvalid` outside a trial (its callers check `negTauInTrial` first).
- Everything else returns an error to the caller (15):
  - `RH_E_DATA` (9): `getLambda` with qcore or qwing not positive, the wavelength table of `SortLambda` that cannot be opened or read, more overlapping transitions at one wavelength than `SortLambda` has room for, and the J, J20 and Imu files that `initSolution` cannot open;
  - `RH_E_INPUT` (1): hydrostatic equilibrium without hydrogen active (`SOLVER = NG`);
  - `RH_E_NUMERIC` (1): a PRD line with more values of rho than the Ng acceleration can index;
  - `RH_E_TRIAL` (3): negative or non-finite populations from the LU fallback (`badPopulations`) and a negative total opacity (`negTauStop`) outside a trial evaluation of G, where no solver can reject the point; in a trial both still mark the point invalid and the solver rejects it, as before. Also rho of a PRD line invalid in `Redistribute`, which would mean a call in a trial (`SOLVER = NG` has none; an invariant of low confidence, LIBRARY.md §3.6);
  - `RH_E_STATE` (1): `MolecularOpacity` for a polarizable molecular line whose Zeeman multiplet was not set up (`molecularPrepare` not called; an invariant of medium confidence).

The boundary moved up. The 23 `ExitOnError` calls inside these modules, to physics and numerics, became `RH_TRY` or `RH_TRY_GOTO`, and the functions that contain them return an `rh_status`, up to the callers outside: 26 functions now return one. Eight give their value through an out-parameter:

- `G_eval(rh, x_in, x_out, &valid)`: `valid` is FALSE for an invalid trial point, as the return value was; a failure is a status;
- `solveSpectrum(..., &dJmax)` and `updatePopulations(..., &dpopsmax)`, with NULL allowed for `solveSpectrum`;
- `asymmetricBlends(..., &Nchanged)`, `MolecularOpacity(..., &flags)`, and in `solver.c` the PRD sub-iterations, the error estimate and the stopping test of `ERROR_LIMIT`.

The callers outside are the programs and the gcheck drivers (`SortLambda`, `initSolution`, `initScatter`, `Iterate`, `solveSpectrum`, `gcheckRun`; 42 calls) and `readAtom` (`getLambda`). They call through `ExitOnError`, which prints the same message and exits with status 70 as before. The physics, converted in Q-54, passes the status on: `backgroundPrepare` that of `molecularPrepare`, and the background workers that of `MolecularOpacity`.

A failure frees and closes what the function holds:

- the solvers (`iterateNg`, `iterateFixedPoint`, `iterateAnderson`, `iterateNewton`) free their work arrays, Ng structures and Gamma as at the end of a run;
- `statEquil`, `statEquilMolecule`, the error estimate, the PRD iterations and `gcheckRun` free their buffers;
- `initSolution` closes the J, J20 and Imu files it opened; the arrays it made belong to the run (phase 4);
- `SortLambda` closes the wavelength table on a failed read, and checks the count before it sizes the table. It also frees the table now, which it never did.

In a trial the solvers reset the trial flag before they pass a failure on. `fdProduct`, the Jacobian product of `NEWTON_KRYLOV`, keeps the callback type of GMRES. It records a failure of G in its context, and its products are zero after it. `iterateNewton` returns the status when GMRES is done.

The large arrays of `initSolution` (J, J20, Jgas, the line-of-sight velocities, the emergent intensities and Gamma of the active atoms and molecules) use `allocMatrixDouble`, which returns `RH_E_NOMEM` (Q-53). Other allocations still abort until phase 4, among them the per-thread buffers of the formal solution.

Unit tests:

- The changed signatures.
- The error paths, in the process, so that LeakSanitizer also checks the frees: `getLambda` with qcore = 0 and `SortLambda` with a missing and a truncated wavelength table (`test_blends`, `RH_E_DATA`); `statEquil` (`test_negpop`) and `negTauStop` (`test_negtau`) outside a trial (`RH_E_TRIAL`).
- `negTauInvalid` outside a trial aborts (SIGABRT).

Not changed here: an error of G in a trial is not turned into a rejected point. `RH_E_TRIAL` from `LTEpops` in `BackgroundOfState` ends the run as before. Making the solvers reject such a point would change what failing runs do.

Results and output unchanged. Phase 3 of the library track (`docs/LIBRARY.md` §6.3). Scripts, checks and logs: `claude/RH/evidence/lib-q55-transfer-nlte`.
