title: Runs report whether they converged

- `Iterate()` now ends with "Converged in N iterations: max change … <
  ITER_LIMIT = …", or with a WARNING "NOT CONVERGED after N iterations: max
  change … >= ITER_LIMIT = …" telling the user that the output is not a
  converged solution. Before, a run that hit `N_MAX_ITER` ended silently and
  wrote its output as if it had converged. Applies to all four geometries.
- Output files and the exit status are unchanged (a non-zero exit status for
  non-convergence is still to be decided: runs with a deliberately small
  `N_MAX_ITER` would then report failure).
- Verified: `1d_falc_h20` reports convergence in 16 iterations,
  `1d_t5750_h6` reports NOT CONVERGED after 200; the full regression suite
  is byte-identical to upstream.
