title: Parabolic Psi* bounded; 2-D example uses Bezier

- The parabolic short-characteristics approximate operator grows like
  1/dtau_dw for a thin downwind interval (values of 12, and thousands before
  a blow-up, were seen). Where it falls outside [0, 1] the linear Psi* is now
  used, in the 1-D, 2-D and 3-D solvers. The intensity keeps the quadratic
  form: Psi* only sets the convergence rate, not the converged solution. The
  bound is tested without dividing by dtau_uw*dtau_dw, which can underflow.
- The shipped 2-D example now uses `S_INTERPOLATION = S_BEZIER3` (the code's
  default) instead of `S_PARABOLIC`, with a note on why.
- Tried and rejected: also falling back to linear for the intensity. It
  removes some crashes but changes converged solutions by up to 16 %.
- Verified: 2-D FAL-C with CaII and parabolic interpolation converges in 15
  iterations instead of 19, to populations within 0.35 % of upstream (new
  stress case `2d_falc_ca_par`). The full regression suite is byte-identical
  to upstream. Not fixed: `1d_v10_ca_par` (moving 1-D atmosphere, parabolic)
  still crashes, now after 5 iterations instead of 3, because the quadratic
  intensity itself overshoots; Bezier converges on that case.
