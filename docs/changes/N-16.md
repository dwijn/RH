title: SOLVER = NG with HYDROSTATIC = TRUE: no hydrostatic step after the last iteration of an unconverged run

`Iterate` (SOLVER = NG, the only solver that allows `HYDROSTATIC = TRUE`; the G solvers refuse it in `readInput`) ends each iteration that did not converge with `Background` (SOLVE_NE = ITERATION) and `Hydrostatic`. When the loop ended at N_MAX_ITER, the last iteration did this too, and the run then wrote its output. `Hydrostatic` rescales only the hydrogen populations to the new nHtot, so the other active atoms (their populations were solved with the old nHtot) were off by the last change of nHtot in the output. A converged run breaks out of the loop before this step and was never affected.

Fix. In `iterateNg` the hydrostatic step is skipped when the loop is about to end (`niter` already incremented past N_MAX_ITER, and past CR_Nstep if that is larger), that is, only after the last iteration of a run that did not converge. Every intermediate step is kept. The final `Background` (the update of ne, the convention of all solvers) is kept. A STOP_RH stop is not covered: the file is tested at the top of the next iteration, after the hydrostatic step of the previous one has run, so the output of a stopped run still has the last step in it (skipping it would need a look-ahead at the stop file; not done).

What was measured. H_6 and Ca II active on FAL-C, SOLVER = NG, HYDROSTATIC = TRUE, SOLVE_NE = ITERATION, one thread. Consistency of the output: max over the depth points without H2 (T outside the range of H2.molecule, where the sum of the H populations of `atmos.out` is nHtot) of |sum of the Ca II populations of `pops.CA.out` / (abundance(Ca) nHtot) - 1|:

| run | c9154c0 | with the fix |
|---|---|---|
| N_MAX_ITER = 3 | 1.05e-1 | 1.1e-6 |
| N_MAX_ITER = 6 | 3.4e-2 | 1.1e-6 |
| converged (ITER_LIMIT = 5e-2, 69 iterations) | 4.4e-16 | 4.4e-16 |

(An earlier measurement with a diagnostic build, sum of n / (abundance nHtot) with the internal nHtot over all depths, gave 3.3e-2 after 3 and 1.3e-2 after 6 iterations, 2.8e-4 after 40, and 4e-16 converged; the table uses only what the output files hold. The 1.1e-6 is the state at the start, present with N_MAX_ITER = 1 where there is no hydrostatic step at all, and not related to this change.) The files of the converged run are byte-identical to c9154c0 (all `*.out` and `*.dat`, except the timings in `time.out`).

Which results change. Only runs with SOLVER = NG and HYDROSTATIC = TRUE that end at N_MAX_ITER: the written atmosphere (nHtot, ne after the last `Background`, and hydrogen populations, which now stay at the nHtot of the last hydrostatic step before the final iteration) and the populations are consistent with each other; the previous output had nHtot, ne and the hydrogen populations one hydrostatic step further than the metal atoms. Converged runs and all other solvers are unchanged. These runs report NOT CONVERGED anyway; the change is in how far the output is from a self-consistent state, not a better solution.

Tests. `tests/e2e/hydrostatic_final.py` (new, registered as `e2e_hydrostatic_final`, about 15 s): the consistency above for a run at N_MAX_ITER = 3 (must be below 1e-5; 1.05e-1 on c9154c0, it fails there) and for a converged run (below 1e-5; 4.4e-16).
