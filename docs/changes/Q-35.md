title: spline.c removed (natural cubic spline, no caller since N-35)

`spline.c` (`splineCoef`, `splineEval` and the reentrant `splineTableInit`/`splineTableEval`/`splineTableFree` with the `SplineTable` type) had no caller outside the unit tests; its last production use went with N-35. A grep of C, CMake, docs, Python, IDL and `tools/` found no other reference (only prose in comments and the unit-test write-up).

**Removed:** `spline.c`, its entry in the `CMakeLists.txt` source list, and the prototypes and the `SplineTable` typedef from `rh.h`. `expspline.c` (`exp_splineCoef`/`exp_splineEval`) is untouched.

**Tests (`tests/unit/test_interp.c`):** `test_spline_table` and `test_spline_order` (natural spline only) are gone, and so are the natural-spline parts of `test_spline_linear_data` and `test_spline_reference` (the node and end-value check). The exponential-spline checks stay unchanged. The small-tension limit of `test_spline_limits` compared `exp_spline` with `splineEval`; it now compares with `spline_ref_natural`, the mpmath solution already in `kernels_reference.h` (the same numbers to 1.6e-16 relative), so that data stays. The header comment, `tests/README.md` and `docs/unit-tests/unit-tests.tex` are updated.

**Results:** no production code calls the removed functions, so results are unchanged: `run_tests.py --exact` is byte-identical.
