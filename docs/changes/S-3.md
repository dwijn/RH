title: SOLVER = ANDERSON: stabilized Anderson acceleration of the map G, with keywords ANDERSON_DEPTH, ANDERSON_DELAY, ANDERSON_COND_MAX, ANDERSON_SAFEGUARD, ANDERSON_VARIABLES, ANDERSON_COEFFICIENTS

Third item of the solver track (docs/SOLVER.md S-3), the replacement for Ng. `SOLVER = ANDERSON` iterates the map G of S-2 with Anderson acceleration (type II, mixing 1; Walker & Ni 2011) on the whole state: the populations of the active atoms and molecules, PRD rho, J, and with `SOLVE_NE = ITERATION` the electron density. The history slides by one every iteration over the last `ANDERSON_DEPTH` (default 5) differences, with one coefficient set for the whole state (`ANDERSON_COEFFICIENTS = GLOBAL`; `PER_BLOCK`, one set per block as Ng per atom, for comparison). The least squares is solved by QR (classical Gram–Schmidt with reorthogonalization, fixed summation order, bit-reproducible), never by normal equations; while the exact condition number of R exceeds `ANDERSON_COND_MAX` (default 1e8) the oldest columns are left out. Variables: `ANDERSON_VARIABLES = LOG` (default), where the residual is the relative change that `ITER_LIMIT` judges and populations stay positive, or `RELATIVE` (linear, scaled by fixed totals); every block of the state gets the same weight (1/√N per entry). Entries without a value in these variables take G's value. The first extrapolation comes after evaluation max(`ANDERSON_DELAY`, 2) (default 2, chosen by a scan of 2, 5 and 10 on four cases). Safeguards: an extrapolated point that is not finite, negative (RELATIVE), or inverts a line or continuum where G's point does not is damped to 1/2 and 1/4 of the step, then replaced by the plain step with the history restarted; after the evaluation, a point whose weighted residual grew by more than `ANDERSON_SAFEGUARD` (default 1; 0 = off) times that of the last accepted point is rejected, the plain step from that point (already computed) is taken and the history restarts from it. One iteration is one G evaluation, rejected ones included. The run stops when the change of an evaluation (MaxChange's definition on x and G(x)) is below `ITER_LIMIT`; the output is that G(x), never an extrapolated point. The counts (extrapolated, plain, rejected, guard actions, columns dropped) are printed at the end and read by `tests/analyze_run.py`. readInput stops on `NG_ORDER > 0` with `ANDERSON`, on any `ANDERSON_*` keyword with another solver, and on the conflicts of `FIXED_POINT` (whose messages now name the solver in use). `ANDERSON_DEPTH = 0` is `FIXED_POINT` without Ng bit for bit. Default runs (`SOLVER = NG`) are unchanged bit for bit. New: `anderson.c` (generic, no RH globals), `iterateAnderson()` in `solver.c`, unit test `test_anderson` (Walker & Ni's equivalence with GMRES on a linear map to 5e-16, depth 0, collinear columns, the safeguard and restart, damping, masked entries, per-block coefficients, reproducibility) and e2e test `e2e_solver_anderson`. Measurements on the S-5 case set follow separately.
