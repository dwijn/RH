title: The map G and SOLVER = FIXED_POINT, with ne in the state; gcheck programs; keyword BACKGROUND_DOUBLE

Second item of the solver track (docs/SOLVER.md S-2 and S-2b). One MALI iteration is now available as a function G of an explicit state vector (populations of active atoms and molecules, PRD rho, J, and with SOLVE_NE = ITERATION the electron density), with no acceleration and a fixed number of PRD sub-iterations inside. The new keyword SOLVER selects NG (the default, unchanged bit for bit) or FIXED_POINT, which iterates x <- G(x), with RH's Ng on G's output when NG_ORDER > 0. Keyword settings that G cannot honour (PRD early exit or PRD Ng, collisional relaxation, hydrostatic equilibrium, LIMIT_MEMORY, and with ne in the state OLD_BACKGROUND and NON_ICE) stop the run when the keywords are read, with a message for each. With ne in the state the background is recomputed from the state at the start of every G: ntotal from its initial value, LTE quantities and collision rates, a chemical equilibrium with the neutral fractions of active atoms taken from the state and a fixed number of Newton steps, the opacities; after the formal solution and statistical equilibrium, ne follows from charge conservation in a fixed number of Newton steps from the state's ne. The new keyword BACKGROUND_DOUBLE stores the background file in double. New programs gcheck_1d, gcheck_2d and gcheck_3d check G on states a run reaches: G twice on the same state, G(x_a), G(x_b), G(x_a) for hidden state, the noise of G (ECnoise) and finite-difference Jacobian products, per block of the state; new ctest e2e_solver_g. Results: FIXED_POINT without Ng reproduces the default solver without Ng (and with PRD_ITER_LIMIT = 0) bit for bit; G is bit-reproducible and free of hidden state on all S-5 cases, in 2-D and 3-D at 4 threads, and with ne in the state (where repeated calls differed by up to 55 % before); 2000 calls keep the descriptors and memory flat; plain G converges 1d_falc_solvene in 859 iterations to a fixed point within 4e-8 of the current code's. The noise of G is 1e-13 to 2e-10 on converged states, except He_large (2e-3). With ne in the state, the float background limits finite-difference Jacobian products to ~3e-3 (double: ~1e-6); SOLVER.md records this as open.
