title: Collision rates given by formulas are checked for sign and finiteness; AR85-CHP takes the proton density from the continuum of the hydrogen model

Collision records with formulas (`SHULL82`, `BADNELL`, `AR85-CDI`, `AR85-CEA`, `AR85-CHP`, `AR85-CHH`, `BURGESS`) were evaluated without a check, unlike the tabulated records, which N-32 interpolates in log-log so that they stay positive and which stop the run at read time when a value is not finite. Measured on the code before this change (`test_collision_formulas`, synthetic records): `SHULL82` with B = -3 gives a negative rate above T1 / ln 3 (-6.8e-8 at 1.8e5 K, in the units of `C`), and so do `BADNELL` with a negative coefficient, `AR85-CDI` with a negative sum (set to zero without a message) and `AR85-CHH` with 1 + c exp(d T/1e4) < 0; `AR85-CHP` read `atmos.H->n[5]`, the continuum only of a hydrogen model of six levels (a bound level for H_20 and beyond the array for fewer levels, where `CP` and `CH+` already used `n[Nlevel - 1]`).

Policy, the same as N-32 where there is a counterpart: what the coefficients alone decide stops the run when the record is read (`collision.c`, `CollisionRate`, ERROR_LEVEL_2, naming atom, keyword and levels): a coefficient that is not finite in any of the formula records; negative A, arad or adi, a negative T0 or T1, or T_col <= 0 with A > 0 in `SHULL82`; a negative energy E_i in `BADNELL`; a shell energy <= 0 in `AR85-CDI`; a negative scale factor in `AR85-CEA` and `BURGESS`; T1 > T2 in `AR85-CHP` and `AR85-CHH`. What depends on T is checked while the rate is evaluated (`rateChecked`): a rate that is not finite stops the run; a negative one is set to zero (as `AR85-CDI` did) and reported with a warning, once per record and run (the routine is called again when the electron density changes), with the number of locations, the smallest value and its temperature. This is why `SHULL82` with B < -1 and `AR85-CHH` with c < -exp(-d T/1e4) are not read-time errors: the factor is negative only above a temperature (T1 / ln(-B)), and the radiative term of `SHULL82` can keep the sum positive; they are clipped where they are negative. `AR85-CHP` and `AR85-CHH` set the rate to zero outside [T1, T2] as before and now say so once per record and run (number of locations and temperature range). The fits of the other formulas are still used at any temperature: their records carry no range.

`AR85-CHP` now takes the proton density from `atmos.H->n[atmos.H->Nlevel - 1]`, the last level of the hydrogen model, as `CP` and `CH+` do (for a passive hydrogen these are the LTE populations).

Numerical check of `Atoms/C_I+II_9.atom`, the only shipped atom with formula records (`SHULL82`, `BADNELL`, `AR85-CDI`, `AR85-CEA`, `SUMMERS`): 61 temperatures from 1e3 to 1e6 K (log spaced, ne = 1e18 m^-3), every rate finite and non-negative, no warning: nothing there is negative or clipped, so the file gives the same rates as before. None of the shipped atoms uses `AR85-CHP`, `AR85-CHH` or `BURGESS`. Seen in passing, not changed (data, to be checked against the sources): all four `AR85-CEA` records of that file give zero rate at all T, because `ar85cea` has formulas only for the Li, Na and Mg to S isoelectronic sequences and C I and C II are the C and B sequences; and the splits of the file between the two C II ²P° levels (g = 2 and 4) are 0.6 : 0.4 for `AR85-CDI`/`AR85-CEA` 0-3, 0-4 and for `SHULL82` and `BADNELL` 3-8, 4-8 (the ratio of the coefficients is 1.5 in each), the reverse of the statistical weights 1 : 2, while `SHULL82` and `BADNELL` 0-3 and 0-4 are the same, unsplit, coefficients.

Tests. `test_collision_formulas` (new, synthetic atom files through `CollisionRate`): the formula records of `C_I+II_9` over 1e3 to 1e6 K are finite, non-negative and silent; `SHULL82` with B = -3 matches the formula with the negative part set to zero (relative 1e-9) and gives one warning, none when called again; `BADNELL`, `AR85-CDI` and `AR85-CHH` negative cases give zero and one warning each; `AR85-CHH` and `AR85-CHP` match their formulas inside the range, are zero outside it, and report the range; `AR85-CHP` uses the last level for a hydrogen of 8 and of 2 levels; the read-time errors (child process, exit status 70) for the cases above, and `SHULL82` with B = -3 is not one. Run against the code before this change the test fails (negative rates, no messages, wrong proton density).

Results do not change: none of the cases of `run_tests.sh` has a formula record, and the rates of the shipped atom `C_I+II_9` are unchanged (no value negative or clipped). Same code upstream.
