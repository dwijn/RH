title: CI: pushes to chrysalis are checked too

CI ran on pushes to `modernize` only. The library track works on its own integration branch, `chrysalis` (`docs/LIBRARY.md` §6.1), where pull requests were checked against their base but the merges into the branch were not. `chrysalis` is now in the push trigger, so every merge into it gets the same jobs as a merge into `modernize`: the build and test matrix, the comparison with the commit before, and the drift from upstream.

The test is the CI run of this pull request's merge into `chrysalis`.
