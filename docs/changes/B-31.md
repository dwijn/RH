title: Hybrid PRD with a single ray uses the right gas-frame mean intensity (changes results)

With `PRD_ANGLE_APPROX` and one ray (`NRAYS = 1` in rhf1d, or an angle set with one ray), the gas-frame mean intensity `Jgas` was wrong in two ways. It was zeroed before each formal solution only for more than one ray, and the formal solvers added to it only for more than one ray, except in the branch for wavelengths without moving or polarized line opacity, which added regardless. So at those wavelengths `Jgas` grew by J with every formal solution (on FAL-C, 27 to 34 times J after 30 iterations), and at the wavelengths of the PRD lines it stayed zero. The populations then differed by 25% from angle-averaged PRD, which must give the same answer in a static atmosphere. The test on the number of rays, meant to leave `Jgas` alone in the final single-ray solutions (`solveray`), is removed; those solutions do not update J, so `Jgas` is not touched there anyway. With one ray, `Jgas` now equals J in a static atmosphere and hybrid PRD gives the same populations as angle-averaged PRD, byte for byte; in a Bifrost column `Jgas` is filled at every wavelength. Runs with more than one ray are unchanged (regression suite byte-identical). Also present upstream.
