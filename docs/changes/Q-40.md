title: Source layout: the library in src/, the geometries in src/geometry/, the examples in examples/

The 92 `.c` files and 24 headers of the library left the repository root, and the four geometry directories left the top level (phase 0 of the library track, `docs/LIBRARY.md` §6.2). A pure move: no source file changed except three `#include` lines in `tools/`.

| Directory | Contents |
|---|---|
| `src/include/` | the shared headers (`rh.h`, `atom.h`, `atmos.h`, `spectrum.h`, `inputs.h`, `constant.h`, `error.h`, `statistics.h`, `background.h`, `xdr.h`) |
| `src/runtime/` | errors, threads, timers and work counters, matrix allocation, FP traps, stop request (7 files) |
| `src/numerics/` | Anderson, Newton–GMRES, MPE, Ng, GTH, LU, interpolation, special functions, quadrature, sorting (16) |
| `src/physics/` | background opacity sources, chemistry, n_e, LTE, collisions, profiles, Voigt, Zeeman, broadening, PRD integrals (29) |
| `src/transfer/` | opacity per wavelength, Bézier and Stokes kernels, negative-τ detector, background scattering (6) |
| `src/nlte/` | iteration, the map G and the outer solvers, rate equations, initial solution, G checks (8) |
| `src/model/` | wavelength grid and active sets (3) |
| `src/io/` | input readers, scratch-file I/O, XDR writers (23) |
| `src/geometry/plane1d/`, `cart2d/`, `cart3d/`, `sphere/` | what was `rhf1d/`, `rhsc2d/`, `rhsc3d/`, `rhsphere/` |
| `examples/rhf1d/`, `rhsc2d/`, `rhsc3d/`, `rhsphere/` | the shipped example runs, formerly `<geometry>/run/`; still two levels below the root, so their `../../Atoms` paths hold |

- **Build.** The programs keep their build directories (`build/rhf1d/rhf1d`, `build/rhsc2d/solveray`, ...), so the test scripts and run directories find them as before. Every `src/` directory is on the library's include path; headers that only one module uses sit next to its sources.
- **Tests.** The unit tests take their geometry from `src/geometry/<name>`; `rhtest.run.template()` finds the examples in `examples/<program>`, and in `<program>/run` in older trees (baselines and references of `run_stress.py`).
- **Not moved:** `tools/`, `tests/`, `docs/`, `python/`, `idl/`, and the data in `Atoms/`, `Molecules/`, `Atmos/`, which move once runs are self-contained (phase 5).

Results do not change (`run_tests.py --exact` against the base).
