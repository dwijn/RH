title: Background scattering iterated at each wavelength with the populations fixed (1-D, S_LINEAR)

The scattering part of the background source function, σ_c J, was converged by a plain lambda iteration: `Formal` used the J of the previous formal solution at that wavelength, one step per sweep, outside the approximate operator. With `RLK_SCATTER = TRUE` every Kurucz line puts (1 − ε) of its opacity into σ_c, and ε is 10⁻⁴–10⁻⁶ in a chromosphere. Such a line needs of order 1/ε sweeps (the measured contraction at a line core in a MURaM column is 0.9995 per sweep). Nothing else converges it, and `ITER_LIMIT` tests only the populations: the run reports convergence while the line cores still change.

**The change.** At a wavelength with the populations fixed, J solves the linear problem J = Λ[(η + σ_c J)/χ]. New `bgscatter.c` iterates it with the step u + (I − A)⁻¹(J_fs(u) − u), where A is the tridiagonal of dJ/du. Each ray's exact row of the operator comes from the new `Piecewise_Linear_1D_tri` and `Piecewise_Bezier3_1D_tri`; the old functions are wrappers. Anderson acceleration (`anderson.c`, depth `BACKGROUND_ANDERSON_DEPTH`, safeguard 1 with window 1) speeds it up. A point where the step or the extrapolation would make J negative takes the lambda value instead.
- **Before the main sweep.** A wavelength is iterated from the J of the previous sweep, and the main sweep starts from the iterated J*. J, the rates, Γ, Jgas of hybrid PRD and the emergent intensity then all come from one formal solution, J = Λ[S(J*)], which differs from J* by about `BACKGROUND_ITER_LIMIT`.
- **Which wavelengths.** Every wavelength is iterated first in the first sweep. After that, a wavelength is iterated while the previous sweep found that the scattering still changes J: the Jacobi step from the main sweep's J changes it by more than `BACKGROUND_ITER_LIMIT` times the albedo. A wavelength whose iteration needed no step drops out. The cost is one more formal solution per wavelength iterated.
- **Where.** In 1-D with `S_INTERPOLATION = S_LINEAR`. The cubic Bézier operator is not positive and the iteration diverges with it (N-52; the next change handles it). Stokes and background polarization keep the lambda iteration, as do 2-D, 3-D and spherical geometry, with a warning if `BACKGROUND_N_MAX_ITER` is set.
- **Memory.** About 3m + 9 vectors of Nspace doubles per thread while a wavelength is iterated; a byte per wavelength for the flag.

New keywords:
- `BACKGROUND_N_MAX_ITER` (50; 0 = the lambda iteration of before).
- `BACKGROUND_ITER_LIMIT` (0.1 × `ERROR_LIMIT`, or 0.1 × `ITER_LIMIT` without it).
- `BACKGROUND_ANDERSON_DEPTH` (3; 0 = no acceleration).
- `BACKGROUND_OPERATOR` (`TRIDIAGONAL`, or `DIAGONAL` for Jacobi).

The log prints, per sweep, the wavelengths iterated, their formal solutions and any that stopped at `BACKGROUND_N_MAX_ITER`.

**Results.** On a two-level slab (unit test, to 10⁻¹⁰):

| | ε = 10⁻⁴ | ε = 10⁻⁶ |
|---|---|---|
| tridiagonal + Anderson(3) | 23 solves | 36 solves |
| tridiagonal, no Anderson | | 95 solves |
| diagonal + Anderson(3) | 494 solves | |

The lambda iteration needs of order 1/ε. On MURaM column col_0434_0521 (H, Fe, Mg active, `S_LINEAR`, `ITER_LIMIT` = 10⁻³), each from `ZERO_RADIATION` and then a restart from its populations:

| | iterations, first / restart | wall, first run (11 threads) | emergent I, restart vs first: median, p99, max |
|---|---|---|---|
| lambda iteration (`BACKGROUND_N_MAX_ITER` = 0) | 118 / 70 | 82 min | 7.8×10⁻⁷, 7.3×10⁻⁵, 7.1×10⁻⁴ |
| this change | 100 / 25 | 80 min | 5.7×10⁻⁸, 6.7×10⁻⁶, 9.5×10⁻⁴ |

- **The converged spectra differ.** The two disagree in the Kurucz line cores by up to 4.9 % (p99 5.4×10⁻³), the same in both pairs: the lambda iteration stops before the scattering in those cores converges.
- **Iterate-first against iterate-after.** An earlier version that iterated after the main sweep agrees with this one to a median of 10⁻⁸ (max 1.2×10⁻⁴). That version broke the identity Jgas = J of hybrid PRD (the `e2e_prd_hybrid` check fails by 2–4×10⁻⁴ once the iteration runs).

New unit test `test_bgscatter`:
- the operator rows of both solvers against the exact (linear) and finite-difference (Bézier) Jacobian;
- the iteration counts above, `BACKGROUND_N_MAX_ITER` as a bound, and positivity;
- the first-sweep, drop-out and pick-up logic of iterating first.

With the default `S_BEZIER3` nothing changes: `run_tests.py --exact` is byte-identical.

Evidence: `claude/RH/evidence/n51-bgscatter/README` (lambda-iteration growth of the cores, the run pairs, `compare_spectra.py`) and `claude/RH/evidence/n52-bezier-lambda/sticky/` (the iterate-first runs).
