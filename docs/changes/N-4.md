title: Check rho > 0 of the PRD lines after each PRD sub-iteration

The PRD redistribution ratio `rho_prd` multiplies the emissivity of a PRD line (`gij` in `Opacity`, `Uji_down` and the source function follow from it), so a `rho <= 0` makes a zero or negative emissivity, and a NaN spreads through the radiation field. `PRDScatter`, `PRDAngleScatter` and the damping of N-38 produce it from the scattering integral of the current radiation field and nothing looked at the result: a bad `rho` went into the next formal solution, and showed up, if at all, as a negative total opacity or a non-finite intensity far away.

`PRDRhoCheck(atom, kr)` (`prdrho.c`) looks at every value of `rho_prd` of a PRD line and reports the first one that is not positive and finite, with the number of them. `prdSubIterations` (`solver.c`, SOLVER = ANDERSON, FIXED_POINT and NEWTON_KRYLOV) calls it for every PRD line after each sub-iteration, before the next formal solution, and `Redistribute` (`redistribute.c`, SOLVER = NG) after the update of each line, after its Ng acceleration. During a trial evaluation of G the trial point is invalid: `negTauInvalid` (N-8's second reason beside a negative total opacity, N-40) makes `G_eval` return FALSE, and ANDERSON rejects the point and NEWTON_KRYLOV halves lambda or zeroes the probe, as for N-40. Anywhere else the run stops with ERROR_LEVEL_2 and a message naming the atom, line (index and levels), wavelength index and wavelength (with PRD_ANGLE_DEP also the ray and direction), location and value, and saying that a non-positive rho gives a negative line emissivity. Nothing is clipped. The check is one pass over rho per sub-iteration, negligible against the scattering integral.

Results do not change where rho is positive, which is everywhere in the test cases and the reproducer: `run_tests.sh --exact` against N-8 passes (see below) and the 2-D FULL_STOKES run with a varying field and PRD Ca II H and K (B-55 inputs, 4 iterations) gives the same log and spectrum as N-8 byte for byte. A natural case of `rho <= 0` was not found in any of these, so the stop and the trial rejection are exercised by the unit test only.

Tests. `test_prdrho` (new): rho on a small grid, with and without PRD_ANGLE_DEP (rows 2 (Nrays la + mu) + to_obs): all positive passes and records nothing; a zero, a negative value, a NaN and an infinity each stop the run outside a trial evaluation (child process, exit status 70) and, inside one, return FALSE with `negTauFound` true until `negTauReset` and a message naming atom, line, wavelength index (ray and direction), location, and the negative line emissivity; rho is unchanged; two bad values are counted.

`ctest`: 35 of 35 with the CI flags (`-DRH_WARNINGS=ON -DRH_WERROR=ON`) and with icx. `clang-format --dry-run --Werror` clean on the changed files. `run_tests.sh --exact` against the N-8 build: passed 38, failed 0 (all 12 cases byte-identical at N = 1, N = 3 and 8 equal N = 1, memory and Kurucz cases pass).
